# Qt 桌面工作台改版设计

**日期：** 2026-08-15  
**范围：** 用 Qt/PySide6 取代 Tkinter 界面层，保留发布内核和现有本地数据。

## 目标

将软件从堆叠式工具窗口改为适合长期写作与发布的桌面工作台。界面应有稳定的文字清晰度、明确的阅读层级和可伸缩的布局；在最小窗口宽度下，顶部选项不能遮挡、裁切或重叠。

## 技术边界

- 新界面采用 Python 3.14、PySide6 和 Qt Widgets；不引入网页壳或云端服务。
- `publisher.service`、`publisher.workflows`、`publisher.browser`、`publisher.short_story_browser`、账号隔离、Edge 登录资料和 `data/` 文件格式全部保持不变。
- `main.py` 改为启动 Qt 界面；旧 Tkinter 文件暂不打包，以便保留历史参考和既有纯函数测试，但新应用不会依赖它。
- PyInstaller 继续生成 Windows 文件夹包，并显式收集 PySide6 运行时组件。
- 不在验证中提交任何真实章节或短故事。

## 视觉与布局

### 应用外壳

- 顶部仅保留应用标识、当前页面标题、任务状态和一个工具菜单。主题、活动记录、帮助、检查更新和账号维护进入工具菜单，不再横向抢占空间。
- 左侧为固定但可收窄的导航栏，提供“小说排程”“短故事发布”和当前账号入口；主内容区使用 `QStackedWidget` 切页。
- 默认使用接近 Codex 的中性灰白工作面、墨色文字、黑色主操作和低对比边线；保留浅色、柔白、深色、黑曜、石墨和暖灰六个主题。
- 使用 Windows 系统的 `Segoe UI Variable Text` 字体；主标题、正文、表格和按钮使用固定字号，不随窗口宽度缩放。

### 自适应规则

- 主窗口最小尺寸为 `980x680`。导航列可收窄；表单页面放在滚动区域中，底部操作始终可到达。
- 顶部状态标签以省略号收短，进度条仅在任务运行时显示；工具菜单始终可见，选项不会因窗口变窄而掉出边界。
- 小说和短故事页面均采用左右分栏：左侧是作品列表，右侧是可滚动的编辑与发布区域。分栏宽度由 `QSplitter` 处理，用户可自行调节。

### 小说页

- 作品列表、添加作品入口、作品概览、排程设置、发布范围、排程表、当天章节和发布操作按工作顺序排列。
- 排程表保留每一天的章节、总字数、状态和当天详情；状态以文字与克制的颜色共同表达。
- 定时发布、立即发布、存草稿、修改正文、修改排期、同步后台、打开 Edge、查看发布清单、从失败处继续和导出诊断全部保留。

### 短故事页

- 短故事列表与编辑表单同样采用左右分栏；文件来源、封面、主分类、附加分类、AI 声明、协议确认、预览、保存和发布均保留。
- 附加分类使用可滚动列表，支持选中任何位置的分类后删除；不改变最多八个总分类的规则。

## 交互与错误处理

- 发布任务沿用现有后台线程和任务事件队列；Qt 用定时器在主线程更新状态和禁用控件。
- 成功只在整批任务结束后汇总提示；登录、验证码、额度、平台风险、协议或实际发布失败继续明确停止并显示原因。
- 更新检查、活动记录、帮助、添加/重命名账号和添加作品改为 Qt 对话框，不改变原有数据调用。
- 主题仍写入原有 `data/ui-settings.json`，读取旧版本主题配置时继续兼容。

## 验证

1. 新增 Qt 界面测试，覆盖：窗口最小尺寸、工具菜单存在、窗口变窄时不会产生顶部控件重叠、主题保存、短故事附加分类滚动与删除。
2. 保留全部发布、排程、分类、账号和更新测试；运行 `python -m unittest discover -s tests -v`。
3. 启动源代码版本，以默认和最小窗口尺寸检查小说页、短故事页、主题切换和工具菜单；不触发真实发布。
4. 运行 `build.ps1` 生成安装包，并检查包内不包含 `data/`、账号资料、Edge 配置或作品正文。
