# 番茄创作发布助手工作台改版设计

**日期：** 2026-08-14  
**范围：** Tkinter 桌面界面的字体、布局、主题和短故事附加分类操作

## 目标

将现有界面从以功能为中心的工具窗口整理为清晰、耐看的创作发布工作台。重点改善主体层级、文字清晰度、排程可读性和短故事分类编辑体验，同时保持所有已验证的发布流程、保存格式和 Edge 登录方式不变。

## 视觉与字体

- 默认主题“Codex 浅色”使用灰白工作区、白色工具栏、墨灰文字和深色主操作，不使用大面积淡蓝、淡绿或棕橙。
- 保留深色和其他对比明显的主题；主题只改变颜色，不改变布局、按钮含义或状态语义。
- 全局采用 `Segoe UI` 的常规与粗体字重，中文交由 Windows 的清晰系统字体回退。正文标签、表格、输入框和按钮提高到清晰可读的固定字号，不使用细字重或随窗口缩放的字号。
- 主按钮、次级按钮、输入框、列表和表格共享统一的边框、内边距和焦点样式。发布动作仍是界面中唯一的高强调按钮。

## 页面结构

### 顶栏

- 顶栏调整为较低、更轻的工具栏：左侧是图标和应用名称，右侧依次是主题、任务状态和进度。
- 任务状态继续复用现有 `_task_status_var`；发布、同步、失败和空闲的行为不改变。

### 小说排程

- 左栏固定显示作品列表和添加作品入口，当前作品具备明确但克制的选中样式。
- 主工作区依次展示作品信息、排程设置、发布范围、排程表、当天章节和操作栏；各区域通过间距和细分隔线区分，不再堆叠厚重卡片。
- 排程表和当天章节表提高表头、行高和状态对比度，完整保留已有状态文字、滚动条、排序和选择回调。

### 短故事发布

- 短故事页和小说页使用相同的侧栏、标题、输入和操作层级。
- 附加分类列表改为固定高度的可滚动列表，并放置垂直滚动条。用户可以滚动至任意一个已选标签，选中后点击“移除所选”即可删除。
- 增加、自动识别、保存和发布时仍使用现有 `StringVar` 与 `_set_story_extra_categories()` 数据路径；附加分类上限仍是 7 个，总分类上限仍是 8 个。
- 旧版 `ui-settings.json` 中的浅色主题会在读取时迁移到“Codex 浅色”；之后保存的新版主题仍按用户的当前选择恢复。

## 边界与错误处理

- 不修改小说排程、后台同步、章节提交、短故事连续队列、分类算法、浏览器选择器或本地数据文件格式。
- 没有作品、没有排程、暂停发布、分类未选择或分类已达上限时，继续显示现有文字提示。
- 发布期间继续禁用现有按钮，错误窗口和停止语义保持不变；界面改版不得隐藏平台风险、额度、验证码或发布失败。
- 默认窗口和最小窗口尺寸均须保留排程表、当天章节、短故事分类列表和发布按钮的可访问性。

## 验证

1. 更新 `tests/test_ui.py`：验证默认工作台的字体和关键样式、主题保存、最小尺寸，以及附加分类列表的滚动与任意位置删除。
2. 运行 `python -m unittest discover -s tests -v`，确保所有发布、排程和短故事回归通过。
3. 运行 `build.ps1`，确认可执行发布包能构建。
4. 启动本地程序，在默认窗口和最小窗口下检查小说页、短故事页、主题切换和分类滚动。该验证不提交真实章节或短故事。
