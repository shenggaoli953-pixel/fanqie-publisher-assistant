# 番茄创作发布助手

本地 Windows 工具，用于整理番茄小说章节排程、同步后台状态，并提交小说章节或短故事。它不会修改原始正文，也不会把账号密码上传到本仓库。

当前版本采用 Qt 桌面工作台，支持独立本地账号空间、小说多种发布操作、短故事连续发布、任务停止、活动记录、更新检查和隐私安全诊断。界面提供多套 Codex 风格主题，作品列表和设置区可自由调整宽度。

## 下载使用

普通用户请在 [Releases](https://github.com/shenggaoli953-pixel/fanqie-publisher-assistant/releases) 下载最新的 `FanqiePublisher-v*.zip`，完整解压后运行：

```text
FanqiePublisher\FanqiePublisher.exe
```

首次启动会在解压目录创建 `data` 文件夹，并在工具自己的 Edge 配置中登录番茄账号。

> 当前发布包尚未使用商业代码签名证书。Windows 可能提示来源未知；若 Smart App Control 直接阻止未签名程序，请不要关闭系统安全设置。

## 使用流程

1. 在“小说排程”添加作品文件夹，确认识别到的章节、起始日期、发布范围和每日限制。支持 `.txt`、`.md`，以及 `第001章-标题`、`第001回-标题`、`chapter-1-标题`、`1-标题` 等常见命名。
2. “发布时间”可以填写一个或多个时间，例如 `08:00, 12:00, 20:00`。同一时段有多章时会按分钟保持顺序。
3. 点击“查看发布清单”核对每章的标题、字数、时间和状态；清单不展示正文。
4. 顶部“本次操作”可选择“定时发布、立即发布、存为草稿、修改正文、修改排期”。修改正文和排期会按当前的起始/结束章节范围处理。
5. 每次任务会先在本地检查当前范围内所有标题和正文，再读取一次后台章节状态；之后连续处理，成功后直接进入下一章。遇到平台风险、额度、验证码、审核中或页面无法确认的情况会在当前章停止。
6. 若有真实失败，选择“从失败处继续”。需要排查时可导出不含正文和账号信息的诊断文件。

短故事在导入后可修改封面、主分类和细分类。点击“发布全部未发布短故事”会先读取一次已发布列表，跳过同名已发布作品，再按软件中的添加顺序连续提交剩余作品；遇到失败或需要人工协议时停止。

## 从源码运行

需要 Windows、Microsoft Edge 和 Python 3.11 或更高版本。

```powershell
git clone https://github.com/shenggaoli953-pixel/fanqie-publisher-assistant.git
cd fanqie-publisher-assistant
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

运行测试：

```powershell
.\.venv\Scripts\python -m unittest discover -s tests -v
```

## 功能

- 递归读取 `.txt`、`.md` 正文；兼容章、回、节、话和常见英文/数字文件名，上传时自动转为不补零的阿拉伯数字章节号。Markdown 只在读取副本时清理标题标记，原文件不改写。
- 按每日字数或章节数生成排程，可指定起始日期、起始章节、结束章节、AI 声明和多个每日发布时间。
- 小说支持定时发布、立即发布、存草稿、修改正文和修改排期；修改正文不会改写章节序号，改排期只处理后台“待发布”章节。
- 每项小说操作会先完成本地正文预检，只读取一次后台分页，自动跳过已有章节；任务停止、失败或需要人工处理时不会跳过当前章继续。
- 遇到错别字、格式或同义的继续/提交提示时会按页面状态推进；平台额度、风险、验证码和页面异常会停止后续提交。
- 支持查看不含正文的发布清单、从失败章节继续，以及导出隐私安全的本地诊断报告。
- 支持短故事导入、封面、分类、AI 声明和试读设置；自动分类宁少勿乱，仍可手动选择至多 8 个分类。
- 点击一次“发布全部未发布短故事”后，只同步一次后台已发布标题，跳过已发布作品，并按软件添加顺序连续提交其余作品。
- 支持创建多个本地账号空间；每个账号拥有独立的排程数据、活动记录和 Edge 登录配置。

## 数据与账号

运行数据、作品路径、Edge 登录配置和本地排程都保存在 `data/`，该目录被 Git 忽略，不会被提交到 GitHub。诊断报告同样不包含正文、标题、路径、账号、浏览器配置或登录信息。每位使用者应使用自己的番茄账号，并自行确认内容、版权和平台规则。

本工具不是番茄官方产品。平台页面、接口、审核和权限规则可能变化；当页面状态无法可靠判断时，工具会停止并保留本地状态，而不是猜测下一步。

## 更新与反馈

新版本会通过 [Releases](https://github.com/shenggaoli953-pixel/fanqie-publisher-assistant/releases) 发布。软件顶部的“更新”只读取公开的 GitHub 最新稳定版信息，发现新版本后由用户自行确认是否打开下载页。反馈问题时请附上软件版本、操作模式、操作步骤和导出的诊断文件；不要发送账号、验证码、Cookie、正文或 Edge 配置目录。
