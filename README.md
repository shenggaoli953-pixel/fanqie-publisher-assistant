# 小说排程发布助手

这是一个本地 Windows 工具，用于管理多本小说的章节排程并提交到番茄作者后台。它不会修改小说正文，也不保存账号、密码或验证码。

## 当前功能

- 递归读取 `第001章-标题.txt` 格式的章节并检查重复章号；大纲、备选稿等非章节 `.txt` 会忽略。
- 每本书独立设置发布模式、限制值和发布时间。
- 支持按每日总字数或每日章节数生成连续排程。
- 支持设置首个发布日期、起始/结束章节和每本作品的 AI 生成声明。
- 保存书籍和排程状态；已提交章节不会重复排入后续队列。
- 某日部分章节未提交时，下一次会先补该日剩余章节，不会跳到后续日期。
- 本地正文出现章节号缺口时，排程停在缺口前；补上文件后会按正确顺序继续排程。
- 每次发布前会读取番茄章节管理的全部分页，以后台实际已有章节校正本地提交记录。
- 已定时章节占用当天额度时，后续缺章会按剩余字数或章节数拆分并顺延；无法排在后续章节之前时会停止。
- 单章超过字数上限时标记为“超限”，不应提交。
- 章节号从文件名中转为阿拉伯数字：`第001章-标题.txt` 会提交为章节号 `1`、标题 `标题`。
- 正文开头若重复写有同一章标题会在上传副本中移除；连续空行会压缩为单次换行，不改变本地 `.txt` 文件。
- 每次只提交首个待发布日，并在章节管理页核验“待发布”和定时时间后才记为成功。

## 启动

```powershell
cd 'C:\Users\11038\Documents\电赛小说\番茄排程发布助手'
python -m unittest discover -s tests -v
python main.py
```

在“添加作品”中选择小说项目目录或正文目录，并输入：

- 作品名
- 起始章节
- 限制方式：`words` 或 `chapters`
- 限制值：由你自行设定
- 发布时间：`HH:MM`，例如 `00:00`
- AI生成：默认“是”，可按作品调整

之后可以在主界面修改限制方式、限制值和发布时间；工具只会重建尚未提交的排程。

## 番茄后台接入

1. 点击“打开番茄后台”，在工具专属的 Edge 窗口中完成登录。
2. 点击“检查后台”，软件会按本地作品名找到番茄后台的对应作品和章节管理页。
3. 点击“发布首日排程”。工具会直接提交最早未完成日期中尚未提交的章节。

出现检测页时，每章会选择“全面检测”；部分章节若直接进入发布设置，则继续定时发布。错别字提示会选择非修改的继续操作，即使平台按钮文字变化也能继续流程。全面检测额度不足、验证码、账号等级、发布额度、内容风险、页面结构异常或字数校验失败都会停止后续操作，不会降级为基础检测、自动重试或绕过平台限制。

填写定时日期和时间后，工具会主动收起番茄的日期/时间选择弹层，再选择 AI 声明，避免日历遮挡“是/否”按钮。

番茄后台的作品名必须与工具中的作品名一致。已经在后台排好的章节，请把本地“起始章节”和“首个发布日期”设到下一章，避免重复提交。
工具在创建章节前也会检查后台全部分页；发现相同章节号和标题时会停止，不会覆盖或重复提交。点击“确认发布”后，工具只等待发布设置对话框关闭再进入下一章，不等待章节管理页刷新为“待发布”。

```powershell
.\build.ps1
```
